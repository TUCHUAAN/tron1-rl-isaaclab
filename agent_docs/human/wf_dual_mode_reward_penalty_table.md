# WF 当前奖励与惩罚

> 本文描述当前代码。下一版 Wheel 简化方案见 `wf_new_mode_judgment_modification_plan.md`。

## 计算方式

```text
step_reward = Σ(term × weight × 0.02 s)
```

正权重通常是奖励，负权重是惩罚。

## 通用项

| 项目 | 权重 | 目的 |
|---|---:|---|
| 存活 `keep_balance` | `+1.0` | 延长 episode |
| 静止 `stand_still` | `-5.0` | 零命令时保持静止 |
| 线速度跟踪 | `+3.0` | 跟踪 `vx/vy` |
| yaw 跟踪 | `+1.0` | 跟踪 `wz` |
| 腿对称 | `+0.5` | 抑制明显不对称 |
| 竖直速度 | `-0.3` | 抑制机身上下抖动 |
| roll/pitch 角速度 | `-0.3` | 抑制摇晃 |
| 关节力矩 | `-1.6e-4` | 降低力矩 |
| 关节加速度 | `-1.5e-7` | 降低高频动作 |
| 关节限位 | `-2.0` | 避免腿关节越界 |
| 功率 | `-2e-5` | 降低能耗 |
| base 接触 | termination | 机身触地立即结束 |
| time out | termination | 20 秒正常结束 |

## Wheel 专用项

| 项目 | 权重 | 说明 |
|---|---:|---|
| 高度跟踪 | `-25.0` | 跟踪局部地面相对高度 |
| 非轮关节速度 | `-0.08` | 抑制腿部快速运动 |
| 动作变化 | `-0.10` | 抑制动作突变 |
| 动作平滑 | `-0.05` | 抑制二阶抖动 |
| 非法接触 | `-1.0` | 惩罚腿部/base 碰撞 |
| 双轮有效接触缺失 | `-4.0` | 地面过滤力与轮下几何联合判断 |
| 水平中性点 | `-4.0` | 只惩罚 base 系 x/y 偏离 |
| 轮空中时间 | `-8.0` | 抑制长时间腾空 |
| 滚动误差 | `-2.0` | 约束轮速与机身速度 |
| 地形姿态 | `-8.0` | 机身姿态跟随局部地形 |
| 落地冲击 | `-0.02` | 惩罚过大落地力 |
| 支撑滑移 | `-0.5` | 惩罚轮地接触点滑移 |

速度和 yaw 正奖励使用：

```text
min(left_contact_confidence, right_contact_confidence)
```

Wheel 已关闭：

- 正常轮速 L2 和固定世界水平姿态惩罚；
- 双轮腾空 termination；
- 旧 x/z 构型、轮距、轮轴法向、轮端竖直速度和 xyz 相对速度项。

## Foot 专用项

| 项目 | 权重 | 说明 |
|---|---:|---|
| 轮关节速度 | `-0.10` | 抑制实际轮速 |
| 非法接触 | `-1.0` | 抑制非轮部件触地 |
| gait 接触时序 | `+1.0` | 内部返回接触/速度偏差 |
| 摆动高度 | `-4.0` | 跟踪 swing height |
| 双轮同时腾空 | `-4.0` | 保留至少一个支撑 |
| 落地冲击 | `-0.02` | 减小落脚冲击 |
| 支撑滑移 | `-0.75` | 减小 stance 滑动 |
| 高度跟踪 | `-30.0` | 跟踪机身高度命令 |

硬约束：

```text
Foot wheel action scale = 0
Foot wheel action offset = 0
```

因此轮速为零不只依赖 reward。
