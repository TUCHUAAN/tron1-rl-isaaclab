## 每脚有效迈步

`MissedSwingTracker` / `MissedSwingPenalty` 分别检查左右脚，零命令同样启用。

- 观察到完整的计划支撑→摆动→支撑转换才结算；出生/reset 后的部分摆动不计。
- 该脚在之前的计划支撑期有真实地面接触；实际离地后，轮缘净空≥1 cm 且无接触持续≥60 ms，才完成一次有效迈步。
- 当前地形过滤接触力≥10 N 判接触，≤5 N 判离地，中间保持状态。
- 摆动结束仍未完成，扣 −0.1；每脚每次摆动只结算一次。另一脚的成功不能抵消本脚漏迈，持续腾空不能当成反复起脚。
- 当前摆动期间局部地形平面/接触信号无效时跳过该次评分，避免误罚；扫描有效性本身需结合回放监控。
- 返回事件数除以 step_dt，抵消 RewardManager 的 dt；这是每次事件成本。原有摆线奖励负责具体抬脚高度，本项仅检查是否有效离地。

它不同于 v9 `Foothold/missed_swings` 诊断：后者统计落脚区域跟踪器到下次摆动仍未确认落地的情况，不是本项的离地完成检查。新项可在 `Reward/pen_missed_swing` 查看。

## 按分量零命令保持

`ZeroCommandHoldTracker` / `ZeroCommandHoldPenalty` 接入 Foot 与 Wheel，各分量独立。

- 判零阈值：vx/vy 为 0.02 m/s，wz 为 0.02 rad/s。
- 连续判零 0.3 s 后启用，给减速/转向结束留出过渡；这是固定延时，不额外等待实际速度降至零。
- 对应分量命令超过阈值就立即解除、清空其历史；再次判零需重新等待并记录参考。
- vx=0：限制前后非期望位移；vy=0：限制侧向非期望位移。每个实际世界位移增量按前后两帧的中间航向投影到机身水平轴，再累计最近 1 s 的有符号位移。允许的运动分量不处罚，转向时不把世界 x/y 错当机身 x/y。
- wz=0：记录固定航向，处罚最短角度差，正确跨越 ±π；前进时也生效，可约束楼梯上的航向偏移。
- 全部命令均为零且完成过渡：额外记录固定世界位置，以到该位置的平面距离替代短窗口 XY 成本，避免长期慢漂。目标不随每个步态周期移动；解除全零后释放位置锚点。
- reset 按环境独立清除全部参考、时间窗和计时；同一步重复读取不推进状态。

| 参数 | Foot | Wheel |
|---|---:|---:|
| 位置死区 | 3 cm | 1.5 cm |
| 死区外位置 Huber 尺度 | 5 cm | 5 cm |
| 航向死区 | 0.03 rad，约 1.72° | 同左 |
| 航向 Huber 尺度 | 0.10 rad | 同左 |
| 每个标量 Huber 成本上限 | 5 | 5 |
| 奖励权重 | −0.5 | −0.5 |

这是密集成本，正常乘 step_dt；不抵消 dt。部分零命令时求启用轴成本之和；全零时为一个径向位置成本加航向成本。Foot 的位置死区更宽，允许踏步摆动。Wheel 原 `stand_still` 仍保留，它约束静止速度；新项约束位移/航向偏差。

部分零命令的平移只有 1 s 记忆，不承诺回到很久以前的轨迹；全零才有固定位置锚点。正负漂移可在窗口内相消，瞬时速度奖励继续处理摇摆。航向使用最短角度差，不记录多圈累计角。参考只用于训练奖励，没有改观测维数或部署控制器；旧模型需要重新训练/微调才能学习约束，新奖励本身不会把旧策略变成位置控制器。
